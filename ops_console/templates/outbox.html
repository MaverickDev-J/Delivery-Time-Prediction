Transactional Outbox Pattern
How the Outbox Pattern Works

When an order is created, the order row AND the event are written in one database transaction. A background relay picks up unpublished events and publishes them to Redis Streams. This prevents the dual-write problem: if the app crashes after writing to the DB but before publishing to the queue, the event would be lost. The outbox guarantees at-least-once delivery.
